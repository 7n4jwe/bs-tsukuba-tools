    ポイントリスト出力（CPのみ）

    座標は印刷地図の軸番号（左下00基準）と一致するXnnnYnnn形式。距離はチェックポイント間（ルート沿い）です。中心が未設定だと座標は算出できないため、先に「地図・印刷」タブで中心を設定してください。

    Google Maps API キーが必要です

    本ツールでは検索精度の高い Google Maps を表示用に使用します。Google Maps Platform の API キー（月 $200 まで無料クレジット、個人利用なら課金されません）を取得して入力してください。

    取得方法: Google Cloud Console で Maps JavaScript API / Places API / Geocoding API を有効化し、認証情報からAPIキーを発行。

    入力したキーは このページのURLハッシュ（#）に保存されます（ブックマーク可、サーバー送信なし）。
